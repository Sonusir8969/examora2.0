Ch-3: Trigonometric Functions 30 Questions

1. The radian measure corresponding to 25° is:

  • A. 5π/36
  • B. 25π/180
  • C. 5π/12
  • D. 5π/18

Answer: A. 5π/36

Explanation: Radian measure = Degree measure × (π / 180) = 25 × (π / 180) = 5π / 36.

2. The degree measure corresponding to 11/16 radians is approximately:

  • A. 39° 22' 30"
  • B. 39° 20' 15"
  • C. 40° 20'
  • D. 38° 22' 30"

Answer: A. 39° 22' 30"

Explanation: Degree measure = (11/16) × (180/π) = (11/16) × (180 × 7 / 22) = 315° / 8 = 39° 22' 30".

3. A wheel makes 360 revolutions in one minute. Through how many radians does it turn in one second?

  • A. 12π
  • B. 6π
  • C. 24π
  • D. 2π

Answer: A. 12π

Explanation: Revolutions per second = 360 / 60 = 6. Angle turned in 1 revolution = 2π rad. In 6 revolutions = 6 × 2π = 12π rad.

4. The value of sin(765°) is:

  • A. 1/√2
  • B. 1/2
  • C. √3/2
  • D. 0

Answer: A. 1/√2

Explanation: sin(765°) = sin(2 × 360° + 45°) = sin(45°) = 1/√2.

5. The value of cosec(-1410°) is:

  • A. 2
  • B. -2
  • C. 1
  • D. -1

Answer: A. 2

Explanation: cosec(-1410°) = -cosec(1410°) = -cosec(4 × 360° - 30°) = -(-cosec 30°) = cosec 30° = 2.

6. The value of tan(19π/3) is:

  • A. √3
  • B. 1/√3
  • C. -√3
  • D. 1

Answer: A. √3

Explanation: tan(19π/3) = tan(6π + π/3) = tan(π/3) = √3.

7. If cos x = -1/2 and x lies in the third quadrant, then value of sin x is:

  • A. -√3/2
  • B. √3/2
  • C. -1/2
  • D. 1/2

Answer: A. -√3/2

Explanation: sin² x = 1 - cos² x = 1 - 1/4 = 3/4. In Quadrant III, sin x is negative, so sin x = -√3/2.

8. The value of cos 15° is:

  • A. (√3 + 1) / (2√2)
  • B. (√3 - 1) / (2√2)
  • C. 1 / (2√2)
  • D. (√3 + 1) / 2

Answer: A. (√3 + 1) / (2√2)

Explanation: cos(45° - 30°) = cos 45° cos 30° + sin 45° sin 30° = (1/√2)(√3/2) + (1/√2)(1/2) = (√3 + 1)/(2√2).

9. The value of sin 15° is:

  • A. (√3 - 1) / (2√2)
  • B. (√3 + 1) / (2√2)
  • C. (1 - √3) / (2√2)
  • D. 1 / (2√2)

Answer: A. (√3 - 1) / (2√2)

Explanation: sin(45° - 30°) = sin 45° cos 30° - cos 45° sin 30° = (1/√2)(√3/2) - (1/√2)(1/2) = (√3 - 1)/(2√2).

10. The value of tan 75° is:

  • A. 2 + √3
  • B. 2 - √3
  • C. √3 + 1
  • D. √3 - 1

Answer: A. 2 + √3

Explanation: tan(45° + 30°) = (tan 45° + tan 30°)/(1 - tan 45° tan 30°) = (1 + 1/√3)/(1 - 1/√3) = (√3 + 1)/(√3 - 1) = 2 + √3.

11. The value of sin(A + B) sin(A - B) is equal to:

  • A. sin² A - sin² B
  • B. cos² A - cos² B
  • C. sin² A + sin² B
  • D. cos² A - sin² B

Answer: A. sin² A - sin² B

Explanation: sin(A + B) sin(A - B) = (sin A cos B + cos A sin B)(sin A cos B - cos A sin B) = sin² A - sin² B.

12. The value of cos(A + B) cos(A - B) is equal to:

  • A. cos² A - sin² B
  • B. cos² A - cos² B
  • C. sin² A - sin² B
  • D. cos² A + cos² B

Answer: A. cos² A - sin² B

Explanation: Using trigonometric identities, cos(A + B) cos(A - B) simplifies to cos² A - sin² B (or cos² B - sin² A).

13. The value of cos 2x in terms of tan x is:

  • A. (1 - tan² x) / (1 + tan² x)
  • B. (2 tan x) / (1 + tan² x)
  • C. (2 tan x) / (1 - tan² x)
  • D. (1 + tan² x) / (1 - tan² x)

Answer: A. (1 - tan² x) / (1 + tan² x)

Explanation: cos 2x = cos² x - sin² x = (cos² x - sin² x)/(cos² x + sin² x). Dividing numerator and denominator by cos² x yields (1 - tan² x)/(1 + tan² x).

14. The value of sin 2x in terms of tan x is:

  • A. (2 tan x) / (1 + tan² x)
  • B. (2 tan x) / (1 - tan² x)
  • C. (1 - tan² x) / (1 + tan² x)
  • D. (tan x) / (1 + tan² x)

Answer: A. (2 tan x) / (1 + tan² x)

Explanation: sin 2x = 2 sin x cos x = (2 sin x cos x)/(cos² x + sin² x). Dividing numerator and denominator by cos² x gives (2 tan x)/(1 + tan² x).

15. The value of tan 2x is equal to:

  • A. (2 tan x) / (1 - tan² x)
  • B. (2 tan x) / (1 + tan² x)
  • C. (1 - tan² x) / (2 tan x)
  • D. (1 + tan² x) / (2 tan x)

Answer: A. (2 tan x) / (1 - tan² x)

Explanation: Standard identity: tan 2x = sin 2x / cos 2x = (2 tan x) / (1 - tan² x).

16. The range of the function f(x) = sin x is:

  • A. [-1, 1]
  • B. (-1, 1)
  • C. [0, 1]
  • D. R

Answer: A. [-1, 1]

Explanation: The minimum and maximum output values of sin x for any real input x are -1 and 1 inclusive.

17. The domain of the function f(x) = tan x is:

  • A. R - {(2n + 1)π/2 : n ∈ Z}
  • B. R
  • C. R - {nπ : n ∈ Z}
  • D. [-1, 1]

Answer: A. R - {(2n + 1)π/2 : n ∈ Z}

Explanation: tan x = sin x / cos x, which is undefined whenever cos x = 0 (odd multiples of π/2).

18. The principal solutions of tan x = -1/√3 are:

  • A. 5π/6 and 11π/6
  • B. π/6 and 7π/6
  • C. 2π/3 and 5π/3
  • D. π/3 and 4π/3

Answer: A. 5π/6 and 11π/6

Explanation: tan x is negative in Quadrants II and IV. x = π - π/6 = 5π/6 and x = 2π - π/6 = 11π/6.

19. The maximum value of 3 sin x + 4 cos x is:

  • A. 5
  • B. 7
  • C. 1
  • D. 12

Answer: A. 5

Explanation: The maximum value of a sin x + b cos x is √(a² + b²) = √(3² + 4²) = √(9 + 16) = 5.

20. The principal value of sin x = 1/2 is:

  • A. π/6
  • B. π/3
  • C. π/4
  • D. 2π/3

Answer: A. π/6

Explanation: Principal value lies in the range [-π/2, π/2]. Since sin(30°) = sin(π/6) = 1/2, the answer is π/6.

21. The value of sin 3x is equal to:

  • A. 3 sin x - 4 sin³ x
  • B. 4 sin³ x - 3 sin x
  • C. 3 sin x + 4 sin³ x
  • D. 4 sin x - 3 sin³ x

Answer: A. 3 sin x - 4 sin³ x

Explanation: Standard triple angle identity for sine is sin 3x = 3 sin x - 4 sin³ x.

22. The value of cos 3x is equal to:

  • A. 4 cos³ x - 3 cos x
  • B. 3 cos x - 4 cos³ x
  • C. 3 cos x + 4 cos³ x
  • D. 4 cos x - 3 cos³ x

Answer: A. 4 cos³ x - 3 cos x

Explanation: Standard triple angle identity for cosine is cos 3x = 4 cos³ x - 3 cos x.

23. The value of cos(π/2 + x) is:

  • A. -sin x
  • B. sin x
  • C. -cos x
  • D. cos x

Answer: A. -sin x

Explanation: Angle (π/2 + x) lies in Quadrant II where cosine is negative, so cos(π/2 + x) = -sin x.

24. The value of sin(π - x) is:

  • A. sin x
  • B. -sin x
  • C. cos x
  • D. -cos x

Answer: A. sin x

Explanation: Angle (π - x) lies in Quadrant II where sine remains positive, so sin(π - x) = sin x.

25. The value of cos(-x) is:

  • A. cos x
  • B. -cos x
  • C. sin x
  • D. -sin x

Answer: A. cos x

Explanation: Cosine is an even function, meaning cos(-x) = cos x.

26. The value of sin(-x) is:

  • A. -sin x
  • B. sin x
  • C. cos x
  • D. -cos x

Answer: A. -sin x

Explanation: Sine is an odd function, meaning sin(-x) = -sin x.

27. The value of (cos x - cos y) is equal to:

  • A. -2 sin((x + y)/2) sin((x - y)/2)
  • B. 2 cos((x + y)/2) cos((x - y)/2)
  • C. 2 sin((x + y)/2) cos((x - y)/2)
  • D. -2 cos((x + y)/2) sin((x - y)/2)

Answer: A. -2 sin((x + y)/2) sin((x - y)/2)

Explanation: Standard sum-to-product formula: cos x - cos y = -2 sin((x + y)/2) sin((x - y)/2).

28. The period of the function f(x) = sin(2x) is:

  • A. π
  • B. 2π
  • C. π/2
  • D. 4π

Answer: A. π

Explanation: Period of sin(kx) is 2π/k. Here k = 2, so Period = 2π / 2 = π.

29. If sin x + cosec x = 2, then value of sin² x + cosec² x is:

  • A. 2
  • B. 4
  • C. 1
  • D. 0

Answer: A. 2

Explanation: Squaring both sides: (sin x + cosec x)² = 4 ⇒ sin² x + cosec² x + 2(sin x)(cosec x) = 4 ⇒ sin² x + cosec² x + 2 = 4 ⇒ sin² x + cosec² x = 2.

30. The value of sin(π/2 - x) is:

  • A. cos x
  • B. -cos x
  • C. sin x
  • D. -sin x

Answer: A. cos x

Explanation: By complementary angle identities, sin(π/2 - x) = cos x.
