Ch-2: Relations and Functions 30 Questions

1. If (x + 1, y - 2) = (3, 1), then the values of x and y are:

  • A. x = 2, y = 3
  • B. x = 3, y = 2
  • C. x = 1, y = 3
  • D. x = 2, y = 1

Answer: A. x = 2, y = 3

Explanation: Equating corresponding components: x + 1 = 3 ⇒ x = 2 and y - 2 = 1 ⇒ y = 3.

2. If set A has 3 elements and set B = {3, 4, 5}, then the number of elements in A × B is:

  • A. 9
  • B. 6
  • C. 3
  • D. 12

Answer: A. 9

Explanation: n(A × B) = n(A) × n(B) = 3 × 3 = 9.

3. If A = {1, 2} and B = {3, 4}, then the number of relations from A to B is:

  • A. 16
  • B. 4
  • C. 8
  • D. 2

Answer: A. 16

Explanation: n(A × B) = 2 × 2 = 4. The total number of relations from A to B is the total number of subsets of A × B, which is 2⁴ = 16.

4. The domain of the relation R = {(x, x²) : x is a prime number less than 10} is:

  • A. {2, 3, 5, 7}
  • B. {4, 9, 25, 49}
  • C. {2, 3, 5, 7, 9}
  • D. {1, 2, 3, 5, 7}

Answer: A. {2, 3, 5, 7}

Explanation: The prime numbers less than 10 are 2, 3, 5, and 7. The domain consists of all first elements in the ordered pairs.

5. The range of the relation R = {(x, x²) : x is a prime number less than 10} is:

  • A. {4, 9, 25, 49}
  • B. {2, 3, 5, 7}
  • C. {1, 4, 9, 25}
  • D. {4, 9, 16, 25}

Answer: A. {4, 9, 25, 49}

Explanation: The range is the set of second elements: 2² = 4, 3² = 9, 5² = 25, 7² = 49.

6. The domain of the real function f(x) = √(x - 2) is:

  • A. [2, ∞)
  • B. (2, ∞)
  • C. (-∞, 2]
  • D. R

Answer: A. [2, ∞)

Explanation: For f(x) to be real, the term under the square root must be non-negative: x - 2 ≥ 0 ⇒ x ≥ 2.

7. The domain of the function f(x) = 1 / (x - 3) is:

  • A. R - {3}
  • B. R
  • C. (3, ∞)
  • D. (-∞, 3)

Answer: A. R - {3}

Explanation: The denominator cannot be zero, so x - 3 ≠ 0 ⇒ x ≠ 3. Thus, domain is all real numbers except 3.

8. The range of the function f(x) = |x| for all x ∈ R is:

  • A. [0, ∞)
  • B. (-∞, 0]
  • C. R
  • D. (0, ∞)

Answer: A. [0, ∞)

Explanation: Absolute value of any real number is always non-negative (greater than or equal to 0).

9. If f(x) = x² + 2x + 1, then the value of f(-1) is:

  • A. 0
  • B. 1
  • C. 2
  • D. 4

Answer: A. 0

Explanation: Substitute x = -1: f(-1) = (-1)² + 2(-1) + 1 = 1 - 2 + 1 = 0.

10. Which of the following relations is a function?

  • A. {(2, 1), (3, 1), (4, 2)}
  • B. {(2, 1), (2, 2), (3, 3)}
  • C. {(1, 2), (1, 3), (1, 4)}
  • D. {(3, 2), (3, 4), (5, 1)}

Answer: A. {(2, 1), (3, 1), (4, 2)}

Explanation: A relation is a function if every element in the domain has a unique image. Options B, C, and D have repeating first elements with different outputs.

11. A relation R from a non-empty set A to a non-empty set B is a subset of:

  • A. A × B
  • B. B × A
  • C. A ∪ B
  • D. A ∩ B

Answer: A. A × B

Explanation: By definition, any relation R from set A to set B is a subset of Cartesian product A × B.

12. The identity function f: R → R is defined by:

  • A. f(x) = x for all x ∈ R
  • B. f(x) = c (constant)
  • C. f(x) = x²
  • D. f(x) = |x|

Answer: A. f(x) = x for all x ∈ R

Explanation: The identity function assigns each real number x to itself.

13. The range of the constant function f(x) = 5 for all x ∈ R is:

  • A. {5}
  • B. R
  • C. [0, 5]
  • D. (0, 5)

Answer: A. {5}

Explanation: Since the output is always 5 regardless of the input x, the range is the singleton set {5}.

14. If f(x) = x³ and g(x) = x + 1, then (f + g)(2) is:

  • A. 11
  • B. 10
  • C. 8
  • D. 9

Answer: A. 11

Explanation: (f + g)(2) = f(2) + g(2) = (2³) + (2 + 1) = 8 + 3 = 11.

15. If f(x) = 2x - 5, then the value of x for which f(x) = 0 is:

  • A. 5/2
  • B. -5/2
  • C. 2/5
  • D. -2/5

Answer: A. 5/2

Explanation: Set 2x - 5 = 0 ⇒ 2x = 5 ⇒ x = 5/2.

16. The signum function f: R → R is defined as f(x) = 1 if x > 0, 0 if x = 0, and -1 if x < 0. Its range is:

  • A. {-1, 0, 1}
  • B. [-1, 1]
  • C. R
  • D. {0, 1}

Answer: A. {-1, 0, 1}

Explanation: The signum function outputs only three distinct values: -1, 0, and 1.

17. The domain of the function f(x) = √(9 - x²) is:

  • A. [-3, 3]
  • B. (-3, 3)
  • C. [0, 3]
  • D. (-∞, -3] ∪ [3, ∞)

Answer: A. [-3, 3]

Explanation: 9 - x² ≥ 0 ⇒ x² ≤ 9 ⇒ -3 ≤ x ≤ 3, so domain is [-3, 3].

18. The range of the function f(x) = √(9 - x²) is:

  • A. [0, 3]
  • B. [-3, 3]
  • C. (0, 3)
  • D. [0, 9]

Answer: A. [0, 3]

Explanation: For x ∈ [-3, 3], 9 - x² lies between 0 and 9, so its square root lies between 0 and 3.

19. The greatest integer function f(x) = [x] takes values in which set?

  • A. Set of all Integers (Z)
  • B. Set of Real Numbers (R)
  • C. Set of Natural Numbers (N)
  • D. Set of Rational Numbers (Q)

Answer: A. Set of all Integers (Z)

Explanation: The greatest integer function always outputs an integer less than or equal to x, so its range is Z.

20. If f(x) = x² and g(x) = 2x + 1, then (fg)(3) is equal to:

  • A. 63
  • B. 54
  • C. 42
  • D. 27

Answer: A. 63

Explanation: (fg)(3) = f(3) × g(3) = (3²) × (2(3) + 1) = 9 × 7 = 63.

21. If A = {1, 2} and B = {a, b}, then A × B is equal to:

  • A. {(1, a), (1, b), (2, a), (2, b)}
  • B. {(a, 1), (b, 1), (a, 2), (b, 2)}
  • C. {(1, 1), (2, 2), (a, a), (b, b)}
  • D. {(1, a), (2, b)}

Answer: A. {(1, a), (1, b), (2, a), (2, b)}

Explanation: Cartesian product A × B contains ordered pairs where first element comes from A and second from B.

22. If A × B = {(a, x), (a, y), (b, x), (b, y)}, then set A is:

  • A. {a, b}
  • B. {x, y}
  • C. {a, x}
  • D. {b, y}

Answer: A. {a, b}

Explanation: Set A consists of all first elements in the ordered pairs of A × B, which are 'a' and 'b'.

23. If n(A) = p and n(B) = q, then total number of non-empty relations from A to B is:

  • A. 2ᵖ𝑞 - 1
  • B. 2ᵖ𝑞
  • C. p × q
  • D. 2ᵖ⁺𝑞

Answer: A. 2ᵖ𝑞 - 1

Explanation: Total relations = 2ᵖ𝑞. Subtracting the empty relation (Ø) leaves 2ᵖ𝑞 - 1 non-empty relations.

24. The domain of the function f(x) = 1 / √(x² - 1) is:

  • A. (-∞, -1) ∪ (1, ∞)
  • B. [-1, 1]
  • C. (-1, 1)
  • D. (-∞, -1] ∪ [1, ∞)

Answer: A. (-∞, -1) ∪ (1, ∞)

Explanation: Expression inside square root in denominator must be strictly positive: x² - 1 > 0 ⇒ x > 1 or x < -1.

25. If f(x) = x³ - 1/x³, then f(x) + f(1/x) equals:

  • A. 0
  • B. 2x³
  • C. -2/x³
  • D. 1

Answer: A. 0

Explanation: f(1/x) = (1/x)³ - 1/(1/x)³ = 1/x³ - x³ = -(x³ - 1/x³) = -f(x). Thus f(x) + f(1/x) = 0.

26. If A × B = Ø, then which of the following must be true?

  • A. Either A = Ø or B = Ø
  • B. Both A ≠ Ø and B ≠ Ø
  • C. A = B
  • D. A ∩ B = Ø

Answer: A. Either A = Ø or B = Ø

Explanation: The Cartesian product is empty if and only if at least one of the sets is empty.

27. If f(x) = log(x), then its domain is:

  • A. (0, ∞)
  • B. [0, ∞)
  • C. R
  • D. R - {0}

Answer: A. (0, ∞)

Explanation: Logarithmic function is defined only for strictly positive real numbers (x > 0).

28. If f(x) = [x], then value of f(2.7) - f(-2.3) is:

  • A. 5
  • B. 4
  • C. 1
  • D. 0

Answer: A. 5

Explanation: [2.7] = 2, [-2.3] = -3. Therefore, 2 - (-3) = 2 + 3 = 5.

29. If f: R → R is given by f(x) = (3 - x³)¹/³, then f(f(x)) is equal to:

  • A. x
  • B. x³
  • C. 3 - x³
  • D. (3 - x³)³

Answer: A. x

Explanation: f(f(x)) = [3 - ((3 - x³)¹/³)³]¹/³ = [3 - (3 - x³)]¹/³ = [x³]¹/³ = x.

30. The range of the function f(x) = x² + 2 for all x ∈ R is:

  • A. [2, ∞)
  • B. (2, ∞)
  • C. [0, ∞)
  • D. R

Answer: A. [2, ∞)

Explanation: Since x² ≥ 0 for all x ∈ R, x² + 2 ≥ 2. Thus, the range is [2, ∞).
