Ch-2: Polynomials 10 Questions

1. Which of the following expressions is a polynomial in one variable?

  • A. 4x² - 3x + 7
  • B. y + 2/y
  • C. 3√t + t√2
  • D. x¹⁰ + y³ + t⁵⁰

Answer: A. 4x² - 3x + 7

Explanation: A polynomial must have whole numbers as exponents of the variable. 4x² - 3x + 7 contains only 'x' with whole number powers (2, 1, 0).

2. What is the degree of the polynomial 5x³ + 4x² + 7x?

  • A. 1
  • B. 2
  • C. 3
  • D. 0

Answer: C. 3

Explanation: The degree of a polynomial is the highest power of the variable in the expression, which is 3 in this case.

3. What is the degree of a non-zero constant polynomial?

  • A. 0
  • B. 1
  • C. Not defined
  • D. Any real number

Answer: A. 0

Explanation: A constant polynomial like 5 can be written as 5x⁰, so its degree is always 0.

4. Find the value of the polynomial p(x) = 5x - 4x² + 3 at x = 0.

  • A. 0
  • B. 3
  • C. -1
  • D. 4

Answer: B. 3

Explanation: Substitute x = 0 into p(x): p(0) = 5(0) - 4(0)² + 3 = 0 - 0 + 3 = 3.

5. What is the zero of the linear polynomial p(x) = 2x + 5?

  • A. 5/2
  • B. -5/2
  • C. -2/5
  • D. 2/5

Answer: B. -5/2

Explanation: Set p(x) = 0 ⇒ 2x + 5 = 0 ⇒ 2x = -5 ⇒ x = -5/2.

6. If x + 1 is a factor of p(x) = x³ + x² + x + 1, then the remainder when p(x) is divided by (x + 1) is:

  • A. 1
  • B. -1
  • C. 0
  • D. 2

Answer: C. 0

Explanation: By Factor Theorem, if (x + 1) is a factor of p(x), then p(-1) must be equal to 0, which represents the remainder.

7. What are the factorized factors of x² - 25?

  • A. (x - 5)(x - 5)
  • B. (x + 5)(x + 5)
  • C. (x + 5)(x - 5)
  • D. (x - 25)(x + 1)

Answer: C. (x + 5)(x - 5)

Explanation: Using the algebraic identity a² - b² = (a + b)(a - b): x² - 5² = (x + 5)(x - 5).

8. The expanded form of (x + 2y + 4z)² is:

  • A. x² + 4y² + 16z² + 4xy + 16yz + 8xz
  • B. x² + 2y² + 4z² + 2xy + 4yz + 4xz
  • C. x² + 4y² + 16z² + 2xy + 8yz + 4xz
  • D. x² + 4y² + 8z² + 4xy + 8yz + 8xz

Answer: A. x² + 4y² + 16z² + 4xy + 16yz + 8xz

Explanation: Using (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca: x² + (2y)² + (4z)² + 2(x)(2y) + 2(2y)(4z) + 2(4z)(x) = x² + 4y² + 16z² + 4xy + 16yz + 8xz.

9. If x + y + z = 0, then x³ + y³ + z³ is equal to:

  • A. 0
  • B. xyz
  • C. 2xyz
  • D. 3xyz

Answer: D. 3xyz

Explanation: From identity x³ + y³ + z³ - 3xyz = (x + y + z)(x² + y² + z² - xy - yz - zx), if (x + y + z) = 0, then x³ + y³ + z³ - 3xyz = 0 ⇒ x³ + y³ + z³ = 3xyz.

10. The coefficient of x² in the polynomial 2 - x² + x³ is:

  • A. 1
  • B. -1
  • C. 2
  • D. 0

Answer: B. -1

Explanation: The term containing x² is -x², which can be written as (-1) × x², so its coefficient is -1.
