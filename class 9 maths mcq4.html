Ch-4: Linear Equations in Two Variables 30 Questions

1. What is the general standard form of a linear equation in two variables?

  • A. ax + b = 0
  • B. ax + by + c = 0
  • C. ax² + by + c = 0
  • D. ax + by² + c = 0

Answer: B. ax + by + c = 0

Explanation: The general form of a linear equation in two variables x and y is ax + by + c = 0, where a, b, and c are real numbers and a, b are not both zero.

2. How many solutions does a linear equation in two variables have?

  • A. Unique solution
  • B. Exactly two solutions
  • C. Infinitely many solutions
  • D. No solution

Answer: C. Infinitely many solutions

Explanation: Every linear equation in two variables represents a straight line on a graph, and every point on that line is a solution, making the number of solutions infinitely many.

3. Express the equation 2x + 3y = 4.37 in the form ax + by + c = 0 and state the values of a, b, and c.

  • A. a = 2, b = 3, c = 4.37
  • B. a = 2, b = 3, c = -4.37
  • C. a = 2, b = -3, c = -4.37
  • D. a = -2, b = 3, c = 4.37

Answer: B. a = 2, b = 3, c = -4.37

Explanation: Rewriting 2x + 3y = 4.37 as 2x + 3y - 4.37 = 0 gives a = 2, b = 3, and c = -4.37.

4. The graph of a linear equation in two variables is always a:

  • A. Circle
  • B. Parabola
  • C. Straight line
  • D. Curved line

Answer: C. Straight line

Explanation: A degree-1 polynomial equation in two variables plots as a straight line on the Cartesian plane.

5. If (2, 0) is a solution of the linear equation 2x + 3y = k, then the value of k is:

  • A. 4
  • B. 6
  • C. 5
  • D. 2

Answer: A. 4

Explanation: Substitute x = 2 and y = 0 into 2x + 3y = k ⇒ 2(2) + 3(0) = k ⇒ k = 4.

6. The equation of the x-axis is written as:

  • A. x = 0
  • B. y = 0
  • C. x + y = 0
  • D. x = y

Answer: B. y = 0

Explanation: On the x-axis, the ordinate (y-coordinate) of every point is always zero. Thus, its equation is y = 0.

7. The equation of the y-axis is represented by:

  • A. x = 0
  • B. y = 0
  • C. x = a
  • D. y = b

Answer: A. x = 0

Explanation: On the y-axis, the abscissa (x-coordinate) of every point is always zero, so its equation is x = 0.

8. Any line parallel to the y-axis is of the form:

  • A. y = a
  • B. x = a
  • C. x + y = a
  • D. y = x

Answer: B. x = a

Explanation: A vertical line parallel to the y-axis has a constant x-coordinate 'a' for all points on it.

9. Any line parallel to the x-axis is of the form:

  • A. x = b
  • B. y = b
  • C. x - y = b
  • D. x + y = 0

Answer: B. y = b

Explanation: A horizontal line parallel to the x-axis has a constant y-coordinate 'b' for all points on it.

10. The point (a, a) always lies on the graph of:

  • A. x + y = 0
  • B. y = x
  • C. x = -y
  • D. xy = 1

Answer: B. y = x

Explanation: For (a, a), both coordinates are equal, which satisfies the linear equation y = x.

11. Which of the following ordered pairs is a solution of x - 2y = 4?

  • A. (0, 2)
  • B. (2, 0)
  • C. (4, 0)
  • D. (1, 1)

Answer: C. (4, 0)

Explanation: Substitute (4, 0) into x - 2y: 4 - 2(0) = 4, which equals RHS.

12. If x = 2, y = 1 is a solution of 2x + 3y = k, then k is:

  • A. 5
  • B. 6
  • C. 7
  • D. 8

Answer: C. 7

Explanation: 2(2) + 3(1) = 4 + 3 = 7 = k.

13. The linear equation 3x + 12 = 0 in two variables can be written as:

  • A. 3x + 0y + 12 = 0
  • B. 0x + 3y + 12 = 0
  • C. 3x + 12y = 0
  • D. 3x + y + 12 = 0

Answer: A. 3x + 0y + 12 = 0

Explanation: To represent a single-variable equation in two variables x and y, write the missing variable with coefficient 0: 3x + 0.y + 12 = 0.

14. The graph of x = -3 is a straight line:

  • A. Parallel to x-axis at distance 3 from origin
  • B. Parallel to y-axis at distance 3 to left of origin
  • C. Passing through the origin
  • D. Parallel to y-axis at distance 3 to right of origin

Answer: B. Parallel to y-axis at distance 3 to left of origin

Explanation: x = -3 is a vertical line parallel to the y-axis situated 3 units to the left of the origin.

15. The cost of a notebook is twice the cost of a pen. Write a linear equation in two variables to represent this statement (x = notebook cost, y = pen cost).

  • A. x + 2y = 0
  • B. x - 2y = 0
  • C. 2x + y = 0
  • D. 2x - y = 0

Answer: B. x - 2y = 0

Explanation: Cost of notebook = 2 × (Cost of pen) ⇒ x = 2y ⇒ x - 2y = 0.

16. The graph of the equation y = mx passes through the:

  • A. x-axis only
  • B. y-axis only
  • C. Origin (0,0)
  • D. Point (1,1) only

Answer: C. Origin (0,0)

Explanation: Substituting x = 0 gives y = m(0) = 0. Therefore, (0, 0) satisfies y = mx, so it passes through the origin.

17. How many linear equations in x and y can be satisfied by x = 1 and y = 2?

  • A. Only one
  • B. Only two
  • C. Only three
  • D. Infinitely many

Answer: D. Infinitely many

Explanation: Through a given single point (1, 2) in a plane, infinitely many straight lines can be drawn, each representing a linear equation.

18. The point (-2, 2) lies on the graph of which equation?

  • A. x + y = 0
  • B. y = 2x
  • C. x - y = 0
  • D. 2x + y = 0

Answer: A. x + y = 0

Explanation: Substitute x = -2 and y = 2 into x + y = 0 ⇒ -2 + 2 = 0. LHS = RHS.

19. If the point (3, 4) lies on the graph of the equation 3y = ax + 7, find the value of a.

  • A. 5/3
  • B. 3/5
  • C. 1
  • D. 4/3

Answer: A. 5/3

Explanation: 3(4) = a(3) + 7 ⇒ 12 = 3a + 7 ⇒ 3a = 5 ⇒ a = 5/3.

20. What is the value of y when x = 0 in the equation 3x + 4y = 12?

  • A. 4
  • B. 3
  • C. 0
  • D. 12

Answer: B. 3

Explanation: Substitute x = 0: 3(0) + 4y = 12 ⇒ 4y = 12 ⇒ y = 3.

21. At what point does the graph of linear equation 2x + 3y = 6 cut the x-axis?

  • A. (0, 2)
  • B. (3, 0)
  • C. (2, 0)
  • D. (0, 3)

Answer: B. (3, 0)

Explanation: On the x-axis, y = 0. Substituting y = 0 into 2x + 3(0) = 6 gives 2x = 6 ⇒ x = 3. So the point is (3, 0).

22. At what point does the graph of linear equation 2x + 3y = 6 intersect the y-axis?

  • A. (0, 2)
  • B. (3, 0)
  • C. (2, 0)
  • D. (0, 3)

Answer: A. (0, 2)

Explanation: On the y-axis, x = 0. Substituting x = 0 into 2(0) + 3y = 6 gives 3y = 6 ⇒ y = 2. So the point is (0, 2).

23. If x = 1 and y = 1 is a solution of x - y = c, then c is equal to:

  • A. 2
  • B. 1
  • C. 0
  • D. -1

Answer: C. 0

Explanation: Substituting x = 1, y = 1 gives 1 - 1 = c ⇒ c = 0.

24. Which of the following is NOT a linear equation in two variables?

  • A. 3x + 2y = 5
  • B. x = y
  • C. x² + y = 4
  • D. x + y - 7 = 0

Answer: C. x² + y = 4

Explanation: In x² + y = 4, the degree of x is 2. A linear equation must have maximum degree 1 for all variables.

25. The distance between graph lines x = 3 and x = -2 is:

  • A. 1 unit
  • B. 5 units
  • C. -5 units
  • D. 6 units

Answer: B. 5 units

Explanation: Distance = |3 - (-2)| = |3 + 2| = 5 units.

26. If the linear equation has solutions (-2, 2), (0, 0), and (2, -2), then its equation is of the form:

  • A. y - x = 0
  • B. x + y = 0
  • C. -2x + y = 0
  • D. -x + 2y = 0

Answer: B. x + y = 0

Explanation: For each pair: -2 + 2 = 0, 0 + 0 = 0, 2 + (-2) = 0. All points satisfy x + y = 0.

27. What is the value of x when y = -1 in equation 2x - 3y = 9?

  • A. 3
  • B. 6
  • C. -3
  • D. 0

Answer: A. 3

Explanation: 2x - 3(-1) = 9 ⇒ 2x + 3 = 9 ⇒ 2x = 6 ⇒ x = 3.

28. The linear equation y = 3 represents a line:

  • A. Parallel to x-axis at distance 3 units above origin
  • B. Parallel to y-axis at distance 3 units right of origin
  • C. Passing through origin
  • D. Parallel to x-axis at distance 3 units below origin

Answer: A. Parallel to x-axis at distance 3 units above origin

Explanation: y = 3 is a horizontal line situated 3 units above the x-axis.

29. An equation of the type y = mx represents a line which always passes through:

  • A. (0, m)
  • B. (m, 0)
  • C. (0, 0)
  • D. (1, 0)

Answer: C. (0, 0)

Explanation: Since there is no constant term (c = 0), setting x = 0 yields y = 0, meaning the line passes through the origin (0, 0).

30. If a linear equation passes through (1, 3) and (2, 5), which of the following is its equation?

  • A. y = 2x + 1
  • B. y = x + 2
  • C. y = 3x
  • D. y = 2x - 1

Answer: A. y = 2x + 1

Explanation: Test (1, 3): 2(1) + 1 = 3. Test (2, 5): 2(2) + 1 = 5. Both points satisfy y = 2x + 1.
